# 使用与修改

## 相册

左上角选择旅行或心动漫剧示例。通过“添加照片”追加自己的照片，拖入文件也可导入；放大界面的替换只作用于当前照片。照片按日期和原有顺序展开，缺少日期可选择默认日期。心情、地点无需填写。

点击左下角署名调整个人名字和相册设置。照片放大后可左右切换、写一句、关联实况视频或删除；照片管理支持批量选择删除，无恢复功能。删除前看清选中内容。

## 音乐

点击随机播放即可开始并换曲；点击歌单查看当前曲目、选择歌曲、添加自己的音乐或调节音量。浏览器限制自动播放，首次需手动点击。

## 实况

一起选择同名照片与视频，或打开照片后关联视频。播放时可听原声。静态 JPEG/PNG 不包含运动画面；仅提供静态照片不能还原实况。不支持的编码请导出 JPG 和 H.264/AAC MP4。

## 修改项目副本

先创建并打开同款，再修改生成的项目；不要改 Skill 安装目录。

| 希望修改 | 对应位置 |
|---|---|
| 署名、相册名、自己的照片和音乐 | 优先在页面内操作 |
| 颜色、字体、间距、按钮外观 | app.css |
| 页面文字和按钮 | index.html |
| 动效、导入、相册和播放交互 | app.js、music-library.js |
| 内置图片和音乐 | 对应 gallery / music-catalog 的 JS 与 JSON 清单和 assets；同时更新两种清单 |

修改后重新打开预览验证对应功能；不要重新生成全部照片或改动无关交互。网站运行时不向 GitHub 上传用户照片。

## 分享

本测试版含第三方素材，先私下验证。要公开给观众使用，需换成可分发素材并确定代码许可。私有仓库链接只对已授权账号可见。127.0.0.1 只在运行项目的机器上可用，不是公开网站地址。

# Photo Moments

用照片和音乐，留下心动的瞬间。

作者：[Sherry小水](https://github.com/XshuiAi) · [原始项目](https://github.com/XshuiAi/photo-moments)

V1 包含完整网页模板、示例照片、音乐与 Skill。支持照片球旋转、滚轮展开合拢、高清查看、左右切图、个人署名、可选心情记录、实况视频、单张及批量删除、随机音乐与歌单。

## 在豆包工作中使用

1. 在本仓库 Releases 下载 `photo-moments-v1.0.0.zip`。私有仓库需要登录有权限的 GitHub 账号。
2. 在豆包工作“技能 → 新建 → 上传技能”上传压缩包；若入口要求文件夹，先解压，选择内含 `SKILL.md` 的 `photo-moments` 文件夹。
3. 新建工作任务，选择已导入的 Photo Moments 技能，发送下面的口令。

> 使用 Photo Moments 技能，先完整运行内置 V1 模板，保留示例照片、音乐、布局、照片球动效和交互，不重新设计。请在独立项目副本中启动预览，检查旋转、滚轮展开合拢、照片放大与左右切换、随机音乐和歌单，给我实际可打开的预览入口。先做出同款，等我看过后再修改。

首次使用会出现个人信息或导入入口；示例相册可通过左上角切换。浏览器中原有的个人上传、编辑和播放记录不会跨平台复制。

当前包已包含素材，不需要让豆包去网上重新寻找。GitHub 链接本身不会自动安装技能；使用私有仓库链接，需要豆包的 GitHub 连接器获准读取该仓库。优先下载 ZIP 后上传技能。

## 本地打开

需要 Python 3.9+。在一个独立工作目录运行：

```sh
python3 /技能所在位置/photo-moments/scripts/create_project.py --name my-moments
cd photo-moments-output/my-moments
python3 server.py --port 4180
```

打开 `http://127.0.0.1:4180/`。不需要 Node 或 npm 即可运行网页。不要直接双击 index.html：音乐和存储需要 HTTP 环境。

## 定制口令

- “保留所有动效，把相册名改成夏日记忆，署名改成我的名字。”
- “只替换我选中的这张照片，其他照片保留。”
- “把背景调成暖白色，按钮用浅灰，其他布局不变。”
- “把我的音乐加入歌单，保留随机播放和音量调节。”

## 运行条件

豆包的附件大小限制、运行环境和预览能力以当前账号实际界面为准，本包尚未经豆包实机验证。若大包不能上传，可使用已授权的 GitHub 连接器读取完整仓库，不能只读取 SKILL.md 而漏掉素材。

实况的静态图与视频需要同时提供。macOS HEIC 转换需要 sips；不兼容的视频转换需要 ffmpeg。其他环境建议导入 JPG + H.264/AAC MP4；没有转换工具时不能保证任意 HEIC/MOV 都能播放。

照片与心情保存在当前浏览器中，不自动同步到其他设备；换设备前可在设置中导出备份。删除没有回收站。

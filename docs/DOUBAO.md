# 豆包使用与分享

Photo Moments 是完整网页项目 + 可调用 Skill。Skill 指导 Agent 复制已有模板、运行和修改；不是让它仅凭文字重新画一个类似页面。

## 仓库里有什么

- `SKILL.md`：使用步骤和修改边界。
- `assets/template/`：完整网页代码、两组示例图片、音乐及本地预览服务。
- `scripts/create_project.py` 与 `template-manifest.json`：在新目录建立经过文件校验的独立副本。
- `docs/demos/`：旅行与人物案例的截图、GIF、视频。
- `README.md`、安装与定制指南、MIT 代码许可、第三方素材声明。

用户在浏览器上传的个人照片、实况视频、日记和名字不包含在仓库或 ZIP 中。模板内有 78 张旅行示例、36 张人物示例；旅行 4 首音乐、人物 8 首音乐。

## 方式一：仓库链接 + 口令

需要豆包能访问该仓库、下载完整文件、运行 Python 并提供浏览器预览。当前仓库为私有，必须通过有权限的账号/连接器获取；把私有链接转发给别人不会自动授予访问权。不要在聊天中粘贴 GitHub 密钥。

复制发送：

```text
请使用 Photo Moments，仓库：
https://github.com/XshuiAi/photo-moments

目标：先运行仓库提供的完整同款，再在独立副本上按我的要求修改。
1. 检查是否能获取这个仓库的完整文件。如果无权访问，请明确提示我上传 Photo-Moments.zip，不要凭介绍重新生成。
2. 阅读 SKILL.md、docs/INSTALL.md 和 docs/DOUBAO.md，获取 assets/template、scripts、references、template-manifest.json 及其中全部图片和音频；不能只读取 README 或只复制 HTML。
3. 在当前任务的独立工作目录，使用 scripts/create_project.py 创建名为 my-moments 的项目。已有同名目录就换一个新名字，不能覆盖我的文件。
4. 使用 Python 3.9+ 启动生成项目的 server.py，选择空闲端口，保持服务运行。不要停止其他项目。
5. 本机环境打开对应的 127.0.0.1 地址；云端环境必须给我平台实际提供、且经浏览器验证能打开的预览地址。没有运行/预览能力时，明确说明限制并交付完整项目，不能编造公网链接。
6. 验证两组相册、360°拖拽、下滚展开和上滚合拢、大图左右切换、随机音乐和歌单。先保留模板布局和素材，不重新设计，不用网络占位图片替换。
7. 给我实际项目目录、启动方法和预览入口。之后所有修改在我的项目副本完成，保留其他现有功能。
```

## 方式二：完整 ZIP

从 Release 下载 `Photo-Moments.zip`。在豆包工作的“新建 → 上传技能”入口按界面允许的格式上传；若需要文件夹，选择解压后含 `SKILL.md` 的 `photo-moments`。再新建任务并选择该技能。

发送上述口令，将开头换成“请使用我已上传的 Photo Moments 技能包，不需要访问 GitHub”。如超过平台大小限制，不要只上传 SKILL.md；改用能下载完整仓库的环境，或由平台提供的文件方式传入完整解压目录。本文不承诺豆包的上传限额或所有账号能力相同。

## 怎样继续改

使用者得到自己的项目副本，可以更换照片和音乐、修改标题、名字、色彩或功能，不需要修改上游仓库。

```text
基于已经运行的 Photo Moments 项目修改，不重新创建。
保持照片球、展开合拢、大图浏览和音乐功能。
把主题名改成“我的夏天”，署名改成我的名字。
用我上传的照片追加到相册，不清空原有照片。
修改完成后重新打开预览并验证。
```

相册数据保存在当前浏览器。换设备、换域名或端口不自动同步；重要相册先导出备份。修改项目文件与网页内导入自己的照片是两种不同操作。

## 你测试时看这几项

- 得到真实可打开的网页，不只是一段介绍、截图或静态设计稿。
- 两个主题能切换；示例数量和歌单完整。
- 拖拽、滚轮、大图翻页和随机播放有效。
- 新增照片保留其他照片；单张替换仅修改该张；单张与批量删除有效。
- 导入照片和对应 MOV，可播放画面与原声；待关联视频可预览、关联和删除。
- 名字、相册标题和上传内容刷新后保留；备份可导出。

本次验证覆盖本地模板与安装包，不包含豆包端实机测试。GitHub 是分发代码与文件的地址，不是在线相册；公开共享网页需要另行部署。默认服务只接受本机访问，云端预览如不支持此方式，需要平台适配，不能把云端 localhost 当成公众链接。

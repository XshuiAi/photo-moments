# 做成自己的 Photo Moments

[返回作品介绍](../README.md)

## 最快的一条路径

1. 先用 Skill 打开两个示例，确认球体和照片墙是你想要的效果。
2. 新建自己的相册，输入名字，上传照片。
3. 添加自己的音乐；愿意写时再补心情和地点。
4. 需要改颜色、布局或功能时，把明确需求交给 Agent。
5. 改完查看效果，再导出相册备份。

## 三种素材操作别混用

| 需求 | 正确操作 |
|---|---|
| 保留已有照片，再加几张 | 在当前相册使用“添加照片” |
| 只换一张 | 放大那张照片，使用“替换这张照片” |
| 全部用自己的照片，但保留示例 | 新建空白相册，再上传 |

只有明确想删除时才删除。单张和批量删除都没有回收站。

## 给 Agent 的修改口令

说清楚“改什么、保留什么、怎么检查”。例如：

```text
在当前 Photo Moments 项目副本里修改：
背景改为暖白色，按钮改成深绿色，名字显示为“小林”。
保留所有照片、歌单、球体旋转、滚轮展开合拢和大图左右切换。
改完打开网页，检查桌面和手机竖屏布局。
```

```text
我要一个纪念毕业旅行的相册，名字叫“我们的夏天”。
新建空白相册，照片用我上传的文件，音乐用我的两首 MP3。
拍摄日期能读取就使用；地点和心情先空着，不自动编写。
保留现有示例，方便我随时切换参考。
```

```text
我要一个人物壁纸收藏，叫“心动角色”。
保留当前动效，把我选中的照片替换为我新上传的壁纸。
保留原图清晰度；不要重复使用同一张图片，也不要擅自找其他角色补数量。
```

## 哪些在页面内改，哪些交给 Agent

名字、相册、照片、音乐、心情和地点可以在页面内管理。配色、按钮排布、动效速度、新增功能等交给 Agent 修改项目文件。

| 文件 | 修改范围 |
|---|---|
| index.html | 页面标题、按钮文案、结构 |
| app.css | 背景、字号、间距、按钮、响应式布局 |
| app.js | 相册操作、导入、大图、球体与照片墙交互 |
| music-library.js | 歌单和随机逻辑 |
| travel-gallery / selected-gallery 的 JS 与 JSON | 内置旅行和人物示例 |
| music-catalog 的 JS 与 JSON | 内置音乐条目 |
| assets/ | 实际图片与音频文件 |

修改内置清单时保持 JS 与 JSON 一致，确保资源文件存在、路径匹配。普通使用者优先通过网页上传，避免手动编辑清单。

## 保留原版

Skill 模板用来再次创建同款；生成的项目副本用来定制。不要在安装目录直接改模板，否则完整性校验会失败。想重新开始时，创建不同名字的新副本。

## 发给别人

想让别人“做同款”：给 Skill 地址或完整安装包，对方用自己的 Agent 运行。想让别人“点链接就看”：需要另行部署成网站；不要发送本机 localhost 地址。
